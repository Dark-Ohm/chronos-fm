# T029 — Форк: тёмная тема и закрытие оверлеев

**Приоритет:** P1 для shell и IDE — они тёмные по умолчанию, а весь
прогон T025/T026 прошёл в `Default Light`.
**Скоуп:** `Source/gpui-component`, только запуск и съёмка. **Кода не
трогать.**
**Переиспользовать:** `overlay.sh` и `crop.sh` из
`report-log/T026-shots/` — харнесс уже написан и проверен.

## Две дыры в одном прогоне

**Тёмная тема.** 62 стори T025 и 13 строк T026 сняты в `Default Light`
(видно в статус-баре каждого кадра). Тёмная не проверялась вообще, хотя
стори `Theme Colors` открывается.

**Закрытие оверлеев.** T026 доказал, что слой появляется. Что он
корректно **исчезает** — не проверялось ни разу: ни Esc, ни клик по
затемнению, ни возврат фокуса на триггер. Для шелла это важнее половины
уже проверенного: залипший оверлей на панели — это залипший оверлей на
весь сеанс.

## Часть A — тёмная тема

Переключение живёт в меню приложения: `crates/story/src/app_menus.rs:67`
— `MenuItem::action("Dark", SwitchThemeMode(ThemeMode::Dark))`. То есть
через строку меню в шапке окна, а не через кнопку на странице.

Снять в тёмной теме подмножество, где поломка темы видна сразу:
`Table`, `Editor`, `Sidebar`, `Chart`, `Input`, `Button`, `Theme Colors`,
плюс один оверлей (`Sheet` или `Notification`).

Что считается дефектом: нечитаемый контраст, элемент, оставшийся
светлым, потерянные границы, иконка, слившаяся с фоном.

## Часть B — закрытие оверлеев

По каждому из шести компонентов T026 — открыть и закрыть:

| Компонент | Закрытие |
|---|---|
| `Tooltip`, `HoverCard` | увести мышь |
| `Notification` | крестик; и отдельно — исчезает ли сам по таймауту |
| `Sheet` | Esc; клик по затемнению; крестик |
| `Menu` | Esc; клик мимо меню |
| `NativeMenu` | Esc; клик мимо |

Для `Sheet` в стори есть готовый стенд «Focus back test» с полем и
кнопкой `Test Action` — им проверяется возврат фокуса после закрытия.

Доказательство закрытия — пара кадров «после открытия» / «после
закрытия», а не один.

## Стены

**Стена 1 — переключение темы через меню, а не через страницу.** Клик по
шапке окна, затем по пункту. Координаты пункта меню считать от кадра
открытого меню, а не угадывать.

**Стена 2 — тема глобальна и переживает переключение стори.** Убедиться,
что после переключения сняты именно тёмные кадры: в статус-баре внизу
справа написано имя активной темы — это дешёвая проверка на каждом
кадре.

**Стена 3 — «исчез» доказывается кадром, а не отсутствием ошибки.**
Кадр после закрытия должен совпадать с `--before`. Если оверлей
уменьшился, но остался, или осталось затемнение без содержимого — это
дефект, и он виден только глазами.

**Стена 4 — таймаут `Notification`.** Тост может исчезать сам. Снять два
кадра с разницей во времени, прежде чем писать «закрылся по крестику» —
иначе припишем крестику то, что сделал таймер.

**Стена 5 — `ydotool` удваивает координаты; окно переезжает между
мониторами.** Геометрию брать из `hyprctl clients -j` в момент прогона.
Проверено в T025 и T026, оба раза стреляло.
