# T017 — Git-панель не следует за Explorer (follow-режим мёртв)

**Приоритет:** P1 — заявленный в T010 режим по умолчанию не работает;
панель полезна только после ручного нажатия Refresh.
**Статус:** баг воспроизведён живьём, корень не установлен (нужен разбор кода).
**Источник:** живой смок релизного бинаря 2026-08-06, приёмка T010.

## Симптом (воспроизведено в обе стороны)

1. Explorer в `/home/neo`, вкладка Git → «Not a git repository». Верно.
2. Explorer уводится в `/home/neo/projects/chronos-ecosystem/Chronos-FM`
   (в листинге виден `.git`), вкладка Git → **по-прежнему** «Not a git
   repository».
3. Нажатие «↻ Refresh» → панель мгновенно наполняется: ветка `main`,
   6 modified, 6 untracked — совпадает с `git status --porcelain`.
4. Explorer возвращается в `/home/neo` (не репозиторий), вкладка Git →
   панель **остаётся** на `//home/neo/projects/chronos-ecosystem/Chronos-FM
   · main` со старым статусом.

Pin выключен (кликался только Refresh). То есть панель не реагирует на
навигацию Explorer ни при входе в репозиторий, ни при выходе из него.

## Что заявлено в T010 (и опровергнуто)

Отчёт `T010-git-tab-live-report.md` §Task 3:

> **Follow (по умолчанию):**
> `WeakEntity<ExplorerPage>::upgrade()?.read(cx).current_path(cx)` —
> читает текущую директорию активной вкладки эксплорера.

и refresh-луп:

> Первый refresh в `start_refresh_loop`; затем цикл:
> `background_executor().timer(400ms)` → проверка `rx.try_recv()`.

Луп просыпается каждые 400 мс, но **тикает только по сигналу из
`refresh_tx`**, который шлёт `GitWatcher` (наблюдатель за `.git` уже
открытого репозитория). Смены директории в Explorer никто в этот канал
не отправляет — отсюда, предположительно, и симптом. Гипотезу проверить
по коду, а не принять на веру.

## Что нужно

1. Установить корень: почему `current_path` не перечитывается (луп не
   зовёт `refresh`? зовёт, но с закешированным путём? `WeakEntity` не
   апгрейдится?). Без установленного корня к правкам не переходить.
2. Follow-режим должен реагировать на смену директории активной вкладки
   Explorer — либо подпиской на событие навигации, либо перечитыванием
   `current_path` в самом лупе.
3. Выход из репозитория обязан возвращать панель в пустое состояние
   «Not a git repository», а не оставлять устаревший статус — сейчас это
   хуже, чем ошибка: показываются несуществующие в текущем контексте данные.
4. Проверить, что Pin по-прежнему фиксирует путь и не ломается правкой.

## Тесты

Юнитом воспроизводится плохо (требуется `ExplorerPage` + GPUI). Минимум —
живой прогон по шагам из «Симптом». Если удастся вынести логику выбора
пути (`follow` vs `pinned`) в свободную функцию — покрыть её юнитом.
