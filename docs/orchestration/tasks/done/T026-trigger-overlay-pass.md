# T026 — Форк: прогон триггерных оверлеев gpui-component

**Приоритет:** P1. Прямое следствие T025: галерея прогнана, но шесть
компонентов существуют ради всплывающего слоя, а снятый кадр
свежеоткрытой стори этот слой не застаёт.
**Скоуп:** `Source/gpui-component`, только запуск и съёмка. **Кода не
трогать вообще** — ни в `Source/`, ни в `Chronos-FM/`.
**Предшественник:** T025 (принят с оговоркой; см. его отчёт, §«доказано»
и §«Что осталось непроверенным» п.5).

## Что доказывать

Шесть компонентов, по одному проходу на каждый. Слой должен появиться в
кадре, иначе строка не засчитана:

| Компонент | Чем открывается |
|---|---|
| `Tooltip` | наведение мыши, без клика |
| `HoverCard` | наведение мыши |
| `Notification` | клик по кнопке-триггеру (проверить все четыре типа: Info / Success / Warning / Error) |
| `Sheet` | клик; открыть **все четыре** стороны — Left / Top / Right / Bottom |
| `Menu` | клик по триггеру, включая подменю |
| `NativeMenu` | клик — **см. стену ниже** |

`Popover` и модалка уже засчитаны в T025 (`Popover.png` — открыт по
умолчанию, `probe-dialog-click.png` — открыт кликом). Повторять не надо.

## Стены

**Стена 1 — `NativeMenu` рисует ОС, и он выходит за окно.** `grim -g` по
геометрии окна его обрежет или не поймает вовсе. Для этой одной строки
снимать **полный вывод** (`grim` без `-g`), а не окно. Для остальных
пяти оконного кадра достаточно. Находка исполнителя T025, в поле не
проверялась — если окажется, что и полный вывод не ловит, это находка
тикета, а не провал.

**Стена 2 — `ydotool` удваивает координаты** под Hyprland. Все клики и
наведения отправлять как `x/2, y/2`.

**Стена 3 — окно переезжает между мониторами.** За прогон T025 геометрия
сменилась с `50,36 1086x692` на `3525,10 945x1180`, и один клик по
устаревшим координатам промахнулся. Цель считать от `hyprctl clients -j`
**в момент прогона**, не от прошлого запуска и не от прошлой стори.

**Стена 4 — `exit 0` ничего не доказывает.** «Открылось» определяется по
кадру, а не по коду возврата и не по логу. Кадр надо **открыть и
посмотреть глазами** — правило существует потому, что в T025 кадр
`Sheet.png` выглядел как успешная стори и ею не был.

**Стена 5 — тайминг.** В T025 `Image` был ошибочно объявлен пустым:
кадр снимали через 1.5 с, а картинка приезжала по сети к 12 с. Для
анимированных оверлеев (`Sheet` выезжает, `Notification` всплывает)
снимать после завершения анимации, и если кадр пуст — переснять с
большей задержкой прежде, чем писать «не открылось».

## Приёмка

- Таблица «компонент → слой в кадре / слоя нет / упало» по всем шести,
  с разбивкой там, где вариантов несколько (4 типа Notification,
  4 стороны Sheet).
- Кадр-доказательство на каждую строку, просмотренный глазами.
- Явно: что не удалось снять и почему.
- `git -C Source diff --stat` пуст по коду — допустимы только новые
  файлы кадров и скриптов, ноль правок в `crates/`.
