**Стена 1.1 — `webview` тянет системные библиотеки.** `wry 0.53.3`

**Стена 1.3 — `exit 0` у примера ничего не значит.** Пример может
подняться и нарисовать пустое окно. Судить по кадру. `ydotool` удваивает
координаты, геометрию брать из `hyprctl clients -j` в момент прогона.

### Стены

**Стена 2.1 — версия `wasm-bindgen` CLI обязана совпадать с крейтом.**
Пакет из репозитория даёт 0.2.126 против 0.2.121 в локе, и это
**гарантированная** ошибка вида «rust wasm file schema version: 0.2.121,
this binary schema version: 0.2.126». Ставить через
`cargo install --version 0.2.121`, а не `pacman -S wasm-bindgen`. Если
решишь двигать версию крейта вместо CLI — это правка манифеста форка,
она **вне скоупа**, останавливайся и пиши.

**Стена 2.2 — `rust-toolchain.toml` крейта требует nightly и он
инертен.** `crates/story-web/rust-toolchain.toml` объявляет
`channel = "nightly"` и `targets = ["wasm32-unknown-unknown"]`, но это
механизм rustup, а rustup в системе нет — файл просто игнорируется, и
сборка пойдёт системным stable 1.97.1. Если крейт упрётся в nightly-фичи
— **это находка, и на ней надо остановиться**: ставить rustup рядом с
системным rust значит менять тулчейн для всех пяти проектов, и это
отдельное решение, не побочный эффект этого тикета.

**Стена 2.3 — `Makefile` не подходит целиком.** Его цель `install`
делает `rustup target add` (у нас нечем) и `cargo install
wasm-bindgen-cli` без версии (см. Стену 2.1). Использовать
`scripts/build-wasm.sh` и `www/` напрямую, `make install` — не запускать.

**Стена 2.4 — web-сборка идёт с другим набором фич.** `story-web`
объявляет и `gpui-component`, и `gpui-component-story` с
`default-features = false`. То есть ни `markdown`, ни `html`, ни `time`,
ни `chart`, ни `lsp`, ни `tree-sitter` — код, который T025 не собирал
ни разу. Ошибки могут прийти именно оттуда, и это законный результат, а
не повод включать фичи.

**Стена 2.5 — доказательство здесь другое.** Это браузер, а не окно
Hyprland. `grim` по геометрии окна снимет браузер целиком; этого
достаточно, но в кадре должно быть видно **саму галерею**, а не пустую
страницу с ошибкой в консоли. Консоль браузера тоже приложить — пустой
белый холст с исключением в консоли выглядит как «почти работает».

**Стена 2.6 — сеть.** `bun install` тянет зависимости из реестра.
Если сети нет или `bun.lock` не сходится — фиксировать и не чинить
обходами.
